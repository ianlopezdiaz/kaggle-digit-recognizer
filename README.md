# A From-Scratch CNN on the Kaggle Digit Recognizer Dataset

This repository presents a compact, from-scratch convolutional neural network case study on the classic **Digit Recognizer** (MNIST) dataset.

The accompanying Quarto website documents the reasoning behind the approach and is available at:

**[https://ianlopezdiaz.github.io/kaggle-digit-recognizer](https://ianlopezdiaz.github.io/kaggle-digit-recognizer)**

---

## Project Overview

MNIST is a well known, trivially solved dataset, so this project is not a benchmark-chasing exercise. The objective is a small CNN trained from scratch (no pretrained weights), built and evaluated carefully: not just accuracy, but a confusion matrix and a look at what the model still gets wrong.

The complete pipeline includes:

* Loading and normalizing the Kaggle CSV pixel data
* A small from-scratch CNN (two convolutional blocks, dropout-regularized dense head)
* A standard supervised training loop
* Evaluation beyond accuracy: confusion matrix and a side-by-side look at correct vs. misclassified examples

---

## Dataset

The project uses the **Digit Recognizer** dataset from Kaggle.

* Competition: [https://www.kaggle.com/competitions/digit-recognizer](https://www.kaggle.com/competitions/digit-recognizer)

28x28 grayscale handwritten digit images (0-9), provided as flattened pixel values in CSV form.

## Running the Project

### Install the dependencies

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

### Get the data

Download `train.csv` (and `test.csv`, if you want Kaggle submission predictions) from the [competition page](https://www.kaggle.com/competitions/digit-recognizer/data) into `data/raw/`.

### Run the notebook

```bash
jupyter lab notebooks/digit_recognizer.ipynb
```

### Run the tests

```bash
pytest
```

## Building the Documentation

This repository uses **Quarto** to generate the project website.

Preview the website locally:

```bash
quarto preview
```

Render the complete site locally (output goes to `_site/`, which is gitignored and not committed):

```bash
quarto render
```

Publish the site to GitHub Pages:

```bash
./scripts/publish.sh
```

This executes the notebook in `notebooks/` in place, then runs `quarto publish gh-pages --no-browser --no-prompt`, which renders the site and pushes it directly to the `gh-pages` branch.
